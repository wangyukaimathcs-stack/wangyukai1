# 047班

纯静态手机竖屏中文剧情游戏。无需安装依赖或后端。

[手机浏览器打开游戏](https://wangyukaimathcs-stack.github.io/wangyukai1/)

## 本地预览

直接双击 `index.html`，或在本文件夹启动任意静态文件服务器后打开首页。

## GitHub Pages

1. 新建一个 Public GitHub 仓库。
2. 将**本文件夹内的所有文件**上传到仓库根目录（包括 `assets` 文件夹）。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`。
4. 保存后，等待 GitHub 提供访问链接。

游戏进度、结局记录与隐藏档案使用浏览器本地存储保存；更换浏览器或清除站点数据会重置记录。
